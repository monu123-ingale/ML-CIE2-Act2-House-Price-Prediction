# ML CIE 2 - House Price Prediction

## Objective
To predict house prices using Linear Regression.

## Dataset
Housing Prices Dataset

Source:
https://www.kaggle.com/datasets/yasserh/housing-prices-dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- KaggleHub
- Google Colab

## Model
Linear Regression

Input Feature: Area
Target Variable: Price

## Evaluation Metrics
- MAE: 1474748.13
- MSE: 3675286604768.19
- RMSE: 1917103.70
- R2 Score: 0.2729
